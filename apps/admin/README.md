# apps/admin

Panel interno de Konnecttia: alta de restaurantes, plan, módulos y complementos, roles por
restaurante y miembros. Solo para el equipo de Konnecttia.

**Estado:** pendiente. De momento el panel interno **no es una app aparte**: vive en
`apps/easyorder` bajo `/interno` y habla con la API en `/plataforma/*`. Motivo, rutas y cómo
moverlo aquí cuando compense: [ADR 0009](../../docs/adr/0009-panel-interno.md).
